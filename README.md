# Servlet CRUD Project
A Java Servlet CRUD application using JDBC and a relational database.
## Features
- Add Employee
- View Employees
- Edit Employee
- Delete Employee
- JDBC Database Connectivity
- Servlet-based request handling
## Technologies
- Java
- Servlet
- JSP/HTML
- JDBC
- Oracle Database
- Apache Tomcat
- Eclipse
- VS Code
- Git
- GitHub
